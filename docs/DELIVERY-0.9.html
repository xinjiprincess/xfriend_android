界面与工作流

Xfriend · 对话 / 专家 / 我的

  • 三项主导航收敛日常入口，保留原 Xfriend 图标与玫瑰品牌强调色。
  • 专家与团队使用卡片展示；编辑进入全屏页面，保留已有专家、团队及其配置。
  • 配置包与蓝图导入提供预览，先检查资源与导入内容，再确认写入。
  • 电脑与平台通过统一连接入口访问，具体执行能力由连接状态与宿主合同决定。

Xsalers · 今日 / 客户 / 复盘 / 我的

  • 四项底栏保留销售工作流，专家与分析设置入口移至复盘和我的。
  • 首页使用今日任务主卡，展示今日待办、逾期跟进与待分析沟通，提供查看跟进及开始复盘入口。
  • 保留客户、沟通记录、专家编辑、分析方式及播放器；未将销售工作流改为通用聊天首页。
  • 保留独立图标与紫色强调色，复用共享外观组件。

共享外观

白灰底色、弱边框、克制的品牌色及轻毛玻璃底栏；明暗跟随系统，主要动作采用至少 48dp 的触控区域。Markdown 正文与链接使用主题色。首页大面积渐变已移除。

响应式布局、大字体、键盘避让、触控区域与各类 Markdown 内容的最终显示效果，仍需在实际安装包上验收。

任务执行与权限

本轮实现范围；手机本地任务与远端电脑任务分别遵守各自执行合同。
能力实现内容验收边界
ask / plan / craft问答、计划、执行接入实际工具权限约束，不仅改变界面文案。按模式验证工具允许与拒绝行为；不得据此声称远端电脑已接受手机模式。
冻结 run 模式任务创建时固定本轮模式，后续切换界面模式不改变运行中任务的权限语义。需验证运行中切换、重连与恢复后仍使用原任务模式。
后台与恢复接入后台任务和恢复流程，保留任务状态供继续查看与处理。恢复已有任务不等于自动重新执行；系统杀进程、断网和账号切换需分别验收。
SSE 与细分错误接入事件流及状态恢复，按认证、授权、接口缺失等原因展示错误。流式完成、事件重放、取消及错误恢复需实测，不以收到首条事件判定任务完成。

手机原生工具 ≠ Python 桌面运行时。手机提供已实现的 Android 原生能力；电脑任务使用桌面宿主的 Python 后端、模型及工具环境。两者不能视为工具、文件访问范围、依赖或权限完全相同，也不因展示同名专家而获得等价执行能力。

本轮不宣称手机模型调用全部验收通过。真实供应商、实际模型配置、语音与图像链路以及工具执行结果，均以验证区补充的设备与测试证据为准。

详细路径、合同边界、测试命令及更新步骤见 DESKTOP-HANDOFF-0.9.txt。以下为该交接记录的摘要，非本报告重新执行的测试结果。

源码修复与已有证据

内置 Go 桥新增精确的 /mobile/v2/ → /api/mobile/v2/ 转发，保留配对、Origin、账号／空间作用域、凭据剥离及登录撤销检查。交接记录载明两组 Go 定向测试通过，Python 移动任务集成测试为 5 passed。

Python 集成使用本地测试身份与模型 fixture，链路经过独立 Python 配对桥。它不等同于“Android 真机 → 内置 Go 桥 → 桌面代理 → 真实模型／工具 → 手机”的完整验收。交接记录未提供 Gradle、完整桌面构建、打包安装或部署完成证明。

原生远端入口的当前边界

  • 输入与会话：v2 创建任务仅接收文本；未支持原生附件上传。当前远端页面每次新发送创建独立任务，恢复 run 是继续查看，不代表连续多轮对话或自动续写。
  • 模式与模型：手机不能为远端任务覆盖 ask / plan / craft、模型或工具权限；使用电脑宿主配置，不向手机下载电脑模型密钥。
  • 团队与会议：普通团队 run 不等于 DSH 会议。原生合同未覆盖 DSH 工作区、会议控制、能力安装或文件传输；复杂操作仍需电脑工作台。
  • 审批：仅在宿主声明支持时，对绑定当前 approval_id 与 summary_hash 的动作批准或拒绝。复杂问卷和参数修改回电脑处理，不支持全局自动批准。
