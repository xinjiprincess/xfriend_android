/opt/xfriend-trial/venv/bin/certbot renew --dry-run --cert-name xfriend-trial-ip

脚本签发正式 shortlived IP 证书，安装 HTTPS 代理，设置每天两次续期检查与证书更新后 Nginx reload。该步骤当前因公网连接超时尚未完成，续期定时器也尚未启用。依据 Let's Encrypt / Certbot 官方说明，IP 证书有效期仅六天。

升级请替换程序后重启 xfriend-trial，保留账本和缓存密钥。需要停用时可 systemctl stop xfriend-trial；不要删除数据库来“恢复试用”。
