单应用端到端验证

在已存在的 Android 37 预览模拟器中覆盖安装合并 APK，保留原本地应用数据。通过隔离合成服务完成以下完整流程：原登录页 → 连接电脑配置 → GET /mobile/status → WebView 配对 → HTTP 页面加载 → WebSocket 往返 → 点击“此手机” → 返回原登录页。结果为 PASSED，见 模拟器验证日志。

测试服务只提供合成账号状态和回显消息，不读取真实电脑文件、账号、工作空间或控制功能。模拟器使用此前临时启动的 4GB 配置；不代表 Android 真机性能验收。

  • 手机已登录状态的侧栏切换、正在执行任务时的确认流程与真实本地资料跨升级保留未做端到端实机验收；其源码路径已接入，运行时原有单元测试继续通过。
