# Android 移植说明

## 技术选择

当前目标是手机直接执行智能体，采用 Kotlin + Jetpack Compose。Compose 处理界面，协程处理任务与取消，OkHttp 访问模型和协同平台，Android Keystore 保存加密密钥。Android 8.0（API 26）起可安装。相比 uni-app，这一选择便于后续使用前台服务、通知、系统文件选择器及设备能力；代价是不能直接复用现有 React 页面，也不自动获得 iOS 版本。

## 模块职责

`MainActivity.kt`：五个页面、ViewModel、专家与资源编辑、系统文件导入。网络和文件持久化在 IO 调度器运行。配置变更保留 ViewModel，但进程退出后只恢复已落盘状态。

`Store.kt`：专家、团队、技能、知识与消息的数据模型。JSON 状态以 AtomicFile 落盘，API Key 使用 Android Keystore AES-GCM 加密保存，自动备份关闭。此版是独立手机工作区，不读取桌面 `~/.octop`。

`AgentRuntime.kt`：组装系统提示、绑定技能和知识摘录，发送 OpenAI 兼容 chat completions，处理工具调用，再向模型提交工具结果，直到最终回答或达到 8 次模型调用上限。工具只能访问各专家的应用私有工作区。失败不生成替代回答；团队按成员顺序执行，已经完成的成员结果会保留。

`PlatformClient.kt` / `PlatformScreen.kt`：移植桌面 `infra/connectors/platform_collaboration.py` 的平台协议。登录前读取验证码配置；需要网页验证码时明确停止；租户选择依靠内存 Cookie，正式会话使用加密 Bearer token。列表只展示当前登录用户所属设备的允许字段。

## 原功能与手机版的对应

| 桌面能力 | Android 首版 |
| --- | --- |
| 专家角色与对话 | 独立本地专家，系统提示、技能与知识绑定 |
| 团队 | 1–8 位专家顺序协作，可调整成员顺序 |
| 技能包 | Markdown 指令导入与编辑，不执行 Python/Shell 插件 |
| 知识库 | UTF-8 文本/Markdown，本地中文双字与 Latin 词项检索 |
| 协同平台 | 登录、空间选择、本人设备发现 |
| Windows 原生/DSH 双引擎 | 移动 Kotlin 工具循环；DSH 尚未移植 |
| 云授权账号 | 尚未对接；平台协同登录不是云授权登录 |

## 验证边界

确定性测试使用受控模型响应检查真实工具结果、上下文隔离、取消、失败和团队执行顺序。不会消耗生产模型额度，也不代表真实供应商模型兼容性已验收。模拟器验证安装及界面操作；真实手机后台行为与真实平台登录需要另行实测。

检索与消息上下文有数量和长度限制，适合轻量手机任务；不等同于桌面完整 RAG/记忆系统。文件工具可以改变应用内工作区文件，取消不撤销已经成功的工具操作。

首版每次检索最多扫描绑定列表前 100 份文档，每份前 100000 个字符，返回最多 5 个片段。导入文件上限为 2 MiB；超过检索字符范围的内容需要拆成多个文档后绑定专家。
