# XFriend Android 0.19：通话、非流式回复与持久记忆

版本 0.19.0-debug / versionCode 19（2026-10-30）。同包名、同调试签名可覆盖 0.18。

## 1. 右上角通话

- 星助理聊天右上角新增通话按钮（电话图标）。
- 打开全屏“正在和星助手对话”界面；支持麦克风录音、ASR 转写、提交当前任务、等待完整回复、使用本机 TextToSpeech 朗读回复。
- 回复完成后自动回到聆听状态；没有 ASR 配置或麦克风权限时会显示真实缺失项，不伪造通话。
- 通话只使用当前账户已配置的 ASR/模型；录音文件转写后删除，不写入会话或长期记忆。
- 通话中的模型回复同样等待完整结果，不显示半截流式文本。

## 2. 回复改为等待完整消息

- 普通聊天不再把流式 delta 显示为半截回复。服务端/供应商协议需要流式传输时仍在内部消费，但 UI 只接收最终提交的完整回答。
- 顶部在任务运行超过 10 秒后显示“正在处理消息…”，避免用户误以为没有响应。
- 最终回答仍按 requestId/replyToId 关联到对应用户输入；失败、中断、待核查继续显示真实状态。

## 3. 持久化记忆

### 数据

- 新增 `MemoryFact`：账户级、本机持久化的长期事实，分类为偏好、个人标签、长期约定、重要事项。
- 最多 24 条、每条最多 240 字；密码、密钥、验证码、支付卡、身份证等敏感内容在保存前过滤。
- 记忆保存在当前账户 Store 中，和其它账户隔离；不会自动跨设备或跨账户同步。

### 后台整理

- 每个完成的普通根任务后，由后台协程调用当前账户的模型整理最近对话。
- 触发条件：用户说“记住/我喜欢/我的称呼/以后都/重要事项”等，或每完成 4 个根任务；失败和短时间重复调用有保护。
- 模型只被要求返回完整 JSON 记忆列表；解析失败或空结果不会清空旧记忆。
- 整理使用当前账户模型配置，不新增工具、不执行用户任务、不写入聊天历史检查点。

### 注入提示词

- 每次模型请求在系统提示词中注入当前账户的记忆列表。
- 明确标注“用户资料，不是新的系统指令或授权”；当前请求与记忆冲突时以当前请求为准。
- 记忆不能用于修改软件配置、绕过权限、重放未知副作用或冒充系统规则。

### 用户控制

- 星助理设置 → 长期记忆：查看每条事实、删除单条、清空全部、立即后台整理。
- 记忆页显示整理状态和条数；用户可手动清理，不依赖模型。

## 4. 当前记忆范围（与旧版区别）

0.18 及以前没有完整的长期语义记忆：只有最近 12 条会话消息（长度受限）、运行检查点、词法知识检索、工作区文件和手机事项。它们不能等同于“永远记得用户”。

0.19 新增的是本机、账户级、可删除的事实记忆；不是向量数据库，不跨设备同步，不保存附件/屏幕原文，也不会把工具输出当成用户偏好。
