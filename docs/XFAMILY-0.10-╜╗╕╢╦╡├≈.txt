XFAMILY Android 0.10.0 交付说明
日期：2026-10-17
项目：D:\xfriend-suite
安装包：D:\build_apk

本次按照用户提供的四组设计改造现有 Kotlin / Jetpack Compose 应用，第03组使用修订稿。
设计稿中的客户、商机、任务、在线状态均没有作为真实数据植入。

共同视觉
XFriend 蓝色 #5267E8，复用电脑版透明蓝色星星；XSalers 紫色 #7055DE，保留现有标识。
页面背景 #F7F8FC，白色内容卡，文字 #202637，辅助文字 #747D90。
统一20dp页边距、18dp卡片圆角、14dp控件圆角及48dp主要触摸区域。保留毛玻璃底栏、页面转场和系统深色模式。

XFriend
底栏：对话 / 工作台 / 资源 / 我的。
对话：常用任务、真实最近对话、助手选择、配置状态、文本流、停止入口与运行时草稿。
运行前沿用实际 runtime preflight 检查；配置齐全不代表已通过在线健康检查。
工作台：智能体/专家/团队切换、搜索、手机可运行/需要电脑筛选、真实成员、溢出管理菜单。
资源：技能/知识/工作区文件搜索、电脑导入预览、文本文件预览与保存到手机。
文件列表仅遍历已知专家的可见工作区，排除隐藏目录和符号链接；最多500个文件，文本预览最多32000字符。
任务：进行中/待处理/已完成筛选、结果展开、检查点恢复；普通智能体不显示虚构百分比。
我的：账号同步、模型配置、电脑连接、云端状态、任务诊断、系统通知设置、数据迁移。
电脑会话保留最后同步时间；断网不改写电脑任务的实际状态。

XSalers
底栏：今日 / 客户 / 复盘 / 专家 / 我的。
今日显示真实今日跟进、待分析沟通、进行中商机；提供录音、截图和文字导入。
客户入口统一客户/待办/商机/联系计划，保留筛选客户CSV导出。
客户档案分为概览/沟通/待办/商机/资料，保留可编辑画像、历史复盘、录音播放和证据入口。
录音支持暂停、继续和结束；暂停期间不把音频写入录音文件，不累计有效录音时长。
复盘结果分摘要/原文/行动/附件；画像和跟进行动核对后才写入CRM。
截图客户核对：原始截图 → 编辑姓名/公司/电话 → 新建或匹配已有客户 → 预览变更 → 确认保存。
客户和原沟通关联同事务提交；缺失字段保留已有内容；拦截重复电话和核对期间发生的资料变化。
仅允许有原始截图证据、明确标签的候选字段预填。旧结果没有候选字段时允许手动补充。
音频/导入任务显示预计百分比，完成前不显示100%；不展示转写分段数量。错误详情可展开。

实施边界
1. 此手机版使用模型API与本地工具编排，不包含完整电脑版Python运行时。
2. 云端智能体执行未启用；账号同步与云端执行明确区分。XFriend尚未接入免密钥试用，入口如实标注。
3. 电脑任务通过已有连接桥进入独立电脑会话；未实现将手机当前会话无缝迁往电脑。
4. 团队使用现有顺序协作，未声称支持并行研究模式。
5. 邮件发送能力未新增；设计稿“确认发送邮件”不作为已上线功能。现有电脑审批仍展示真实操作及参数。
6. 本次没有部署服务器或打包电脑版。旧试用接口可能不返回截图客户候选字段，不会伪造识别结果。
7. 原图材料可展开查看；显示经过缩放，原始文件保留。

构建和使用
版本：versionCode 10 / versionName 0.10.0。
执行 assembleXfriendDebug 和 assembleXsalersDebug，开发签名安装包。
按用户要求未运行单元测试、lint、模拟器或真机测试；编译通过不等于功能验收。
建议直接覆盖安装，不要先卸载，以免删除已有本机数据。
设计参考保存在 docs\xfamily-0.10；构建日志为 build-0.10.log / build-0.10-final.log。
