二、重塑后的共同视觉
1. 令牌层：XfDesign.kt 统一提供亮/暗 XfColors、XfType、XfDimens、XfShapes、XfElevation；页面不再直接写颜色与字号。
2. 暖纸画布：浅色画布 #F6F5F1、白色表面 #FFFFFF、主文字 #1B1C1F、分隔线 #E5E2DA；深色画布 #0E0F12、表面 #181A1F、主文字 #F1F2F4。
3. 单一主色、5 组色板：靛蓝 #4F5DF0 / 青绿 #0E9384 / 琥珀 #B26B00 / 玫瑰 #D94F6B / 紫罗兰 #7055DE（XSalers 品牌色）。XFriend 默认靛蓝、XSalers 默认紫罗兰；设置页可切换，立即生效。
4. 亮/暗主题：跟随系统 / 浅色 / 深色；本机 SharedPreferences（xf_appearance）保存，不进入账号同步。
5. 图标：XfIcons.kt 手工实现 60 个 24 视窗、1.75 stroke、圆角线帽的线性图标；导航 20dp、行内 17dp、强调 24dp。
6. 组件：XfComponents.kt 共 28 个共享组件（XfCard / XfButton / XfStatusChip / XfListRow / XfTextField / XfSegmented / XfDialog / XfEmptyState / XfBanner 等），主要页面、详情与 32 处确认/编辑弹窗统一使用。
7. 壳层：XfTopBar 顶栏（56dp）、ProductBottomBar 底栏（80dp 内容高 + 顶部 1dp 线 + Haze 毛玻璃 + 选中主色胶囊）；系统导航栏 insets 保留。
8. 外观设置入口：XFriend「我的 → 外观」、XSalers「我的 → 外观」，提供主题模式、5 色板、预览与系统通知设置。

三、XFriend（4 底栏：对话 / 工作台 / 资源 / 我的）
- 对话：欢迎/最近任务/助手选择、会话消息、工具行、结果卡、附件、发送/停止保持既有能力，视觉统一。
- 工作台：智能体/专家/团队、搜索与运行条件筛选、编辑/导入、选择后进入对话。
- 资源：技能/知识/工作区文件、预览后导入、文本预览与保存。
- 我的：账号与同步、模型、电脑连接、任务诊断、迁移、外观、通知、退出。
- 既有详情：模型配置、平台设备、任务中心、电脑会话、连接、同步、市场、蓝图、设计专家、外观等均可达。
- 未改变：本机模型 API 执行、顺序协作团队、检查点恢复、电脑独立会话、云端执行未启用、免密钥试用未接通。

四、XSalers（5 底栏：今日 / 客户 / 复盘 / 专家 / 我的）
- 今日：今日跟进、待分析沟通、进行中商机；录音、截图、文字导入。
- 客户：客户/待办/商机/联系计划、客户档案（概览/沟通/待办/商机/资料）、导入与筛选 CSV 导出。
- 复盘：录音暂停/继续/结束、摘要/原文/行动/附件、任务中心与失败重试。
- 专家：专家/团队、AI 设计、编辑、市场与运行条件。
- 我的：云同步、模型、连接、迁移、导入导出、会员/试用、电话保护、外观、退出。
- 未改变：Room 客户数据、录音/截图/复盘链路、AI 建议先核对后写入、CRM 不自动改成交状态。

七、实施边界与未验证项
1. 手机是 Kotlin 编排 + 模型 API，不含完整电脑版 Python 运行时；云端智能体执行未启用。
2. XFriend 免密钥试用未接通；XSalers 试用/订阅按现有真实状态展示，订阅支付未接。
3. 团队为顺序协作，不声称并行研究；群聊/会议/决策档案未实现，不加入口。
4. 电脑任务为独立远程会话，手机会话不能无缝迁移到电脑；审批只覆盖宿主声明的真实动作。
5. 截图导入只在有原始证据和标签时预填，不伪造识别结果；邮件发送未实现。
6. 交付为开发签名 APK，非应用商店发布包；服务端部署、桌面安装包、生产签名与上架不在本次范围。
7. 0.11 最终正式构建已通过（见五），模拟器 QA 回归通过（见六，report.md §11）；真机验收未执行，模拟器 QA 为合成数据验收，不能替代真机/真实账号/真实模型验收。首轮截图对应修复前构建，最终截图见 docs\qa-0.11\ *-reg.png 与 report.md §11。旧版本交付物保留在交付目录，当前应选择名称中 0.11.0 的文件。
