六、手机原生入口尚未覆盖的能力

1. 附件：v2 创建任务仅接收文本，不支持图片/文件上传或附件引用。旧网页上传能力不代表此原生任务合同支持附件。
2. 多轮：服务端合同接受 thread_id，但当前 FriendRemote 页面每次新发送创建独立任务，尚未串接连续多轮会话。恢复已有 run 是继续查看，不是自动续写或重新执行。
3. 模式：手机不能为远端任务指定问答/计划/执行模式，不能宣称手机所选模式已在电脑端实施权限限制。
4. 模型：不支持手机覆盖本轮模型或工具/权限配置，使用电脑宿主配置；不向手机下发电脑模型密钥。
5. 会议：普通团队 run 不等于 DSH 会议。原生 v2 未提供 DSH 工作区或会议资源/控制合同，复杂操作需进入电脑工作台。
6. 安装及传输：原生 v2 未声明能力安装、文件传输等能力，不能因桌面其他接口存在就标记手机已支持。
7. 审批：仅在宿主声明支持时，允许对当前 approval_id 与 summary_hash 绑定的动作批准或拒绝。问卷、修改参数等复杂交互回电脑版处理；不支持全局自动批准，也不能承诺跨宿主重启恢复待审批操作。
